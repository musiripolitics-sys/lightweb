# Hero photos

Export these frames from the Figma file and drop them here with these exact names:

- `interior.jpg` — the boutique interior shot (node 327-1767)
- `exterior.jpg` — the building-at-dusk shot (node 392-5665)

Until the files exist, the Interior/Exterior pages render a dark gradient
fallback (see `.photo-bg` in `src/app/globals.css`). No code change is needed
once the images are added.
